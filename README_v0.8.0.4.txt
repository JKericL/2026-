v0.8.0.4 · 문항 이미지 로딩 개선
=================================

변경 파일
---------
- app.source.js

수정 내용
---------
1. 보기 선택 시 renderQuiz()를 다시 호출하지 않도록 수정
   - 기존에는 답변을 하나 선택할 때마다 현재 문항 전체 DOM이 재생성됨
   - 그 과정에서 큰 PNG 이미지도 다시 생성/디코딩되어 모바일에서 순간적인 로딩/깜빡임이 생길 수 있었음
   - 이제 답변 선택 시 선택 표시만 갱신함

2. 다음 문항 이미지 사전 로딩
   - 현재 문항이 표시되면 다음 문항 이미지를 Image()로 미리 캐시에 로드
   - '다음' 버튼을 눌렀을 때 이미지가 더 빨리 표시되도록 개선

3. 이미지 decoding="async" 적용
   - 큰 이미지 디코딩이 화면 렌더링을 오래 막지 않도록 개선

적용 방법
---------
1. 프로젝트의 기존 app.source.js를 이 파일로 덮어쓰기
2. build-app.bat 실행
3. 버전 입력: 0.8.0.4
4. GitHub Desktop에서 app.source.js / app.min.js / index.html 변경 확인
5. Commit -> Push

NAS 서버 수정 및 Docker 재빌드는 필요하지 않습니다.

참고
----
이번 수정은 PNG 파일을 그대로 사용하는 상태에서 체감 로딩을 줄이는 코드 개선입니다.
그래도 느리다면 다음 단계로 question-01~20.png를 WebP로 변환하면 실제 전송 용량까지 크게 줄일 수 있습니다.
