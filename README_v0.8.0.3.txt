v0.8.0.3 변경사항
====================

문제
----
- 팀(지부) 전체 보기에서 '집계 중' 카드의 팀명과 배지가 카드마다 다른 위치로 밀리는 현상
- 참여 완료 카드와 집계 중 카드의 내부 정렬이 서로 달라 전체 목록이 깨져 보이는 현상

수정
----
- 모든 카드를 동일한 4열 고정 구조로 통일
  1열: 팀(지부)명
  2열: 대표 MBTI 또는 '집계 중'
  3열: 주요 기질
  4열: 상세보기
- 집계 중인 팀도 MBTI가 표시될 위치에 '집계 중' 배지를 고정
- DOM 순서와 관계없이 CSS grid-column / grid-row로 위치 강제
- 1040px 이하에서는 전체 목록 1열 전환
- 모바일에서도 동일한 위치 체계를 유지

적용 파일
---------
- team-overview.css 만 기존 파일에 덮어쓰기

참고
----
브라우저에서 기존 CSS가 캐시되어 보이면 강력 새로고침(Ctrl+F5)을 해주세요.
index.html의 team-overview.css 캐시 버전이 0.8.0.2라면
?v=0.8.0.3 으로 바꾸면 더 확실합니다.
